# 市调分析方法与验证

## 工作原则

先读取 [来源与规则](references/sources-and-rules.md)，确认书稿依据和规则适用范围。涉及截止时间、页数、权重、匿名、AI、提交方式时，联网核验目标届次、组别和阶段的正式文件；核验失败就标明待核实，不妨碍先做研究内容。不要将书稿示例写成赛事硬性规则。

默认中文。先查看用户已有材料与当前进度；只询问会改变方案的缺失信息，其余说明假设后继续。无原始数据时只提供方案、待填模板或明确标识的演示，不编造样本、统计量、访谈、参考文献或获奖身份。按用户任务深度交付；局部修改不强制重做全流程。

## 目标

依据书稿第3、5、6章，把每个方法绑定到研究问题、数据条件和可解释输出。先确定任务是描述、比较、解释、分群、预测还是探索概念，再选模型。

## 数据进入分析的关口

- 确认分析单位、观察期、样本来源、概率/非概率设计、层/群/权重、重复测量、问卷版本、纳排规则及数据字典。没有完整框和已知抽取机制时，不称简单随机抽样。
- 原始数据只读保留；清理、分析与输出分层。检查字段和题号、重编码、反向计分、多选展开、跳题、重复、逻辑冲突及缺失机制。区分不适用、拒答、不知道和系统缺失。
- 异常以多项证据人工复核，不仅凭时长、同IP或连续同选项删样本。日志记录规则、依据、命中数、处理与版本；比较关键清理规则对结论的影响。
- 报告接触、回收、排除与分析样本流转。各模型因缺失而有不同n时分别说明。不为显著性反复改分组、删题或筛样本。

## 方法决策表

| 任务/资料 | 可选方法 | 先核查 | 主要交付与限制 |
|---|---|---|---|
| 现状与分布 | 频数、比例、均值/中位数、离散及区间 | 测量层次、偏态、分母、权重、样本覆盖 | 样本画像与边界；不能仅凭样本大推断有代表性 |
| 分类变量关联 | 交叉表、卡方或精确检验；复杂设计用相应修正 | 独立性、稀疏格、重复观测 | 分组比例、关联量与区间，非因果 |
| 连续/有序指标差异 | t/Welch、方差分析或适当秩检验；配对用配对方法 | 独立或配对、分布、异方差、等级含义 | 差异幅度、效应量与区间；秩检验不笼统说成均值检验 |
| 多题项潜在维度 | EFA；有预设结构时CFA | 构念语义、题项相关、分布、样本与估计法 | 维度、载荷和测量证据；EFA/CFA同样本不是独立验证 |
| 用户分群 | 适合变量类型的聚类/混合模型 | 量纲、异常、冗余变量、距离、权重与渠道 | 稳定群组、外部画像、触达规则；不把命名当固定人格 |
| 连续/二分类/有序/多类/计数结果 | 线性、Logistic、有序或多项、Poisson/负二项等 | 编码参照、结果分布、共线性、残差或过度离散、层级依赖 | 系数/优势比/概率或计数比及区间；条件关联不等于因果 |
| 理论潜变量路径 | SEM与间接效应估计 | 先过测量模型、识别、样本、估计法、拟合及竞争模型 | 路径与间接效应区间；横截面中介不证明传递机制 |
| 时间序列 | 分解、适当时序模型、滚动预测 | 时间口径、趋势季节、自相关、异常和结构变化 | 时间留出与简单基线、预测区间；不能随机打乱时序 |
| 新现象的概念探索 | 访谈内容/主题分析；符合设计时用扎根理论 | 招募、录音转写、同意、编码链和负例 | 原话→编码→范畴→解释，饱和有证据；无迭代理论抽样不包装为完整扎根 |
| 平台评论与开放题 | 人工内容分析、词频共现、主题/情感模型 | 来源覆盖、去重、领域词、标签与人工验证 | 代表文本、稳定性、验证误差；词云不能替代分析，评论频次不等于总体率 |
| 预测与机器学习 | 与目标及样本匹配的基线和预测模型 | 数据泄漏、类别不平衡、组别/时间划分 | 独立测试表现、校准/误差和群体表现；特征重要度不等于因果效应 |

## 重点判断

抽样：样本量综合目标精度、效应大小、亚组、模型复杂度、设计效应与无回答；公式假设写清，概率样本公式不能证明便利样本精度。复杂设计分析需使用层、群和权重及相应方差估计。加权报告未加权n、权重来源、分布和假设，不能声称校准消除自选择。

测量：先检查反向题与概念覆盖，再看信效度。α并非全问卷必做，也不证明单维性或效度；人口学题和形成性指标不机械合算α。EFA结合平行分析/碎石图、语义与旋转；CFA报告估计法及适当指标，不以单阈值通过替代判断。测量不稳定时停止解释SEM结构路径，修订设计或退回探索、描述与质性证据。

比较：同时报告方向、幅度、不确定性和实际意义。多组、多指标检验说明多重比较策略；“一组显著另一组不显著”不能证明组间效应不同，应直接做交互或差异检验。跨群体量表比较注意测量等值。

模型：先写变量和设定依据，再估计与诊断，最后解释；不通过不断尝试直到显著选择结果。Logistic优势比不当风险比，标准化系数不当原始单位变化。稳健标准误不修复遗漏变量。拟合好和控制变量多均不证明因果；无可信识别时用“相关/预测/机制线索”。

预测：划分训练/验证/测试，预处理与特征选择仅在训练折拟合；同一对象/门店的记录按组隔离，时序按时间隔离。与朴素基线比较；分类结合精确率、召回、F1、混淆矩阵、区分与校准，按任务选取，不全列作装饰。小样本不为复杂度硬用机器学习。

质性和文本：说明代码本、编码例与复核/分歧处理；自动分类抽取有代表性的人工核验集，报告误差与适用语境。多源资料统一对象、时间及概念再整合，不能把条数当人数或任意拼接个人记录。

## 输出与验证

先交分析预案：`问题｜变量类型与编码｜样本/设计｜方法及选择理由｜假设诊断｜结果形式｜验证与替代方案｜不能回答什么`。如有真实数据和执行条件，再提供数据质量摘要、可复现语法或代码、核心表图与解释、稳健性和局限。

冻结数据、记录软件版本与随机种子；代码和图表对应同一版本。敏感性检查由实际风险决定：缺失、权重、异常规则、设定、分群稳定性等，不机械堆检验。保留计划/修正/探索分析区别及不显著结果。无法运行的软件输出只可解释其可见内容，不能声称已重现。

完成时回答：每个问题由什么证据回答、前提是否满足、结果在何种条件下变化、能支持何种行动；数据不足时给降级方案或补采要求。
