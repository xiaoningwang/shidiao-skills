# 市调注意事项与质量审查

## 工作原则

先读取 [来源与规则](references/sources-and-rules.md)，确认书稿依据和规则适用范围。涉及截止时间、页数、权重、匿名、AI、提交方式时，联网核验目标届次、组别和阶段的正式文件；核验失败就标明待核实，不妨碍先做研究内容。不要将书稿示例写成赛事硬性规则。

默认中文。先查看用户已有材料与当前进度；只询问会改变方案的缺失信息，其余说明假设后继续。无原始数据时只提供方案、待填模板或明确标识的演示，不编造样本、统计量、访谈、参考文献或获奖身份。按用户任务深度交付；局部修改不强制重做全流程。

## 目标

依据书稿第3—4、7—9章与当届文件，把注意事项转化为可核验问题及修复动作。审查深度服从当前阶段，不能用格式检查掩盖设计和数据问题。

## 先确定审查口径

查看届次、组别、学校与赛区、自由/企业命题、所处阶段、截止时间、已有材料。建立规则表：`事项｜届次/组别/阶段｜原文位置与链接｜发布日期/核验日｜正式要求｜地方执行要求｜状态`。文件未提供或无法读取时列“未核实”，不自动判违规。

书稿20/30/30/20的本科报告框架可作诊断参考，不能作为第十七届正式评分。页数、格式、匿名、查重、AI披露、文件命名、答辩时长必须查当届适用附件。全国完成日不是学校材料提交日，按适用的更早操作节点倒排。留学生组和知识赛适用对象尤其需要单独核对。

## 分阶段关口

| 阶段 | 检查的证据 | 典型问题与修复 |
|---|---|---|
| 立项 | 问题定义、总体边界、渠道和授权、资源表 | 总体过大或不可接触：缩题/换设计；不能靠增加模型补救 |
| 方案 | 抽样步骤、样本规划、问题—变量—题项矩阵、伦理说明 | 无抽样框却称随机、题目不能回答目标：重写入样和测量方案 |
| 预调查 | 招募记录、认知反馈、时长与跳转、试清理和试分析、修订表 | 只试填无链路检查：补测关键流程；10份课堂练习不是普遍有效预调查样本门槛 |
| 正式实施 | 培训、样本接触及拒访、批次与渠道、版本及回访记录 | 随意替补、诱导作答、版本混杂：定位影响并修订或补采，保留变化 |
| 数据验收 | 原始文件、字典、流转、清理规则与异常核验、冻结版本 | 批量删快答/同IP：复核证据并检查清理敏感性；不直接改原始值 |
| 分析 | 问题对应、前提诊断、测量质量、代码、稳健性 | 方法堆叠、泄漏、测量失败仍解释路径：简化或暂停该结论 |
| 写作 | 结果索引、引用、结论—建议表、真实来源 | 结论越界、虚构ROI、软件截图堆砌：回溯结果并重写 |
| 提交/答辩 | 正式清单、匿名与版本、文件可打开、PPT及备份、计时排练 | 截止混淆、匿名遗漏、数字不同版：逐项核对并留提交凭证 |

## 真实性与过程质量

核对样本是否实际符合筛选条件、调查渠道和计划是否一致、访谈是否可回溯、照片是否真实属于项目。接触数、回收数、剔除数、有效n及各模型n要能衔接；多渠道合并检查重复和编码。质疑真实性时记录可见异常与待核查证据，不把同设备、快速作答或某一规律直接认定为造假。

不生成问卷回答冒充回收，不编造企业采纳证明、合作授权、访谈录音、现场照片或导师签字。发现关键证据缺口时可先完成其余部分；受影响结论标待核实，必要时建议补采、删除结论或调整范围，不能以包装替代。

## 伦理与AI

只收集完成任务必要的信息；招募说明自愿、用途与退出方式，涉及脆弱群体和敏感信息按真实场景核对机构要求。对公开文本、截图、录音、照片和第三方量表检查权限及识别风险。可见于网络不代表可任意采集和公开。对隐私或合规需给出具体法律判断时另核对现行官方依据，不凭书稿作法律结论。

原始敏感资料限制访问，公开报告去标识化，避免由引语、位置和身份组合重新识别。保留与项目适配的存储和删除安排，不为证明调查而无限收集设备/定位信息。

区分研究诚信建议与当届AI正式规定。AI可辅助题项草案、代码、文本预编码和语言修订，但须核验；记录工具/模型、日期、用途、输入资料类型、人工复核和成果影响，按赛事要求披露。不得上传未获授权的可识别资料，不把生成内容伪装成田野证据，学生必须理解并能独立解释核心调查和分析。

## 提交前可执行核对

按当届清单逐项确认正文/附录/PPT/声明等必需文件，不先验断言必须哪些文件。检查文件名、版本、页数计入范围、格式、引用、匿名范围、元数据/批注/修订痕迹/页眉页脚/图中标识；匿名要求尚未取得时列待确认，不主动删除研究来源。打开最终导出文件看图表、公式、目录页码和字体，PPT准备可离线打开的备份。正式评审稿与带身份存档稿清楚区分。

所有材料统一样本量、指标口径和核心结论。检查上传是否成功、回执是否留存；技能的审查结论不等于已经提交，实际提交仍依用户请求和工具能力执行。

## 审查交付

输出`编号｜阶段/位置｜问题｜可见证据或缺口｜性质｜影响｜修复动作｜验收证据`。性质区分：已确认规则不符、研究方法问题、材料缺失、待核实规则、表达改进。优先级按是否影响真实性、解释有效性、正式受理和修复成本判断，不给没有官方依据的预计扣分。

结论使用“可进入下一阶段”“补齐具体证据后复核”“关键结论暂不支持”等可操作表述。列出已审查和未能核查的范围；材料不全不宣布全面合规或获奖保证。复核以修复后的真实成果为准。
